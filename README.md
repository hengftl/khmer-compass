# Khmer Compass 🇰🇭🧭

Khmer Compass is a simple and lightweight web application designed to help users understand **Khmer directions, orientation, and compass-related concepts** in a clear and accessible way.  
The project is built using modern web technologies and is optimized for fast iteration using StackBlitz.

🔗 **Live Editor (StackBlitz):**  
https://stackblitz.com/~/github.com/hengftl/khmer-compass

---

## ✨ Features

- 🧭 Compass-style direction display
- 🇰🇭 Khmer language–friendly labels and concepts
- ⚡ Fast development using StackBlitz
- 🌐 Runs directly in the browser (no local setup required)
- 📱 Responsive and lightweight UI

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (or TypeScript if applicable)
- **Runtime:** Browser
- **Editor / Dev Environment:** StackBlitz
- **Version Control:** Git & GitHub

---

## 🚀 Getting Started

### Option 1: Run with StackBlitz (Recommended)

1. Open the project in StackBlitz:
   https://stackblitz.com/~/github.com/hengftl/khmer-compass
2. Start editing — changes will reflect instantly in the preview.

### Option 2: Run Locally

```bash
git clone https://github.com/hengftl/khmer-compass.git
cd khmer-compass
````

Then open `index.html` in your browser
(or run with a local dev server if your setup requires it).
